# EduVault – Student Management System

A full-featured React student management portal with routing, authentication, and multiple modules.

## 🚀 Getting Started

### Prerequisites
- Node.js 16+ and npm

### Install & Run

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)

## 📦 Features

| Module | Description |
|--------|-------------|
| **Registration** | New student sign-up with full profile |
| **Login** | Secure authentication |
| **Dashboard** | Overview of student stats, courses & announcements |
| **Student Details** | View & edit personal/academic info |
| **Scholarship** | Browse and apply for scholarships |
| **Payment** | Fee selection, checkout & payment history |
| **CGPA Calculator** | Calculate semester GPA and cumulative CGPA |

## 🛠 Tech Stack
- React 18
- React Router v6
- CSS Variables for theming
- Google Fonts (Syne + DM Sans)
